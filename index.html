💡 Как использовать?

1

Добавьте игры и задания для них во вкладке «Игры»

2

Создайте список участников во вкладке «Игроки»

3

Выберите режим и запустите рулетку!

4

Для стримов подключите OBS Overlay через вкладку «Стример»

🎮 Режимы рулетки

  • Полный рандом — игра + задание + игрок
  • Сначала игра — выбор игры, затем задания для всех
  • Только игрок — выбор случайного участника
  • Только задание — случайное задание из игры
