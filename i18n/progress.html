🤝 How to Add a New Language

  1. Copy i18n/en.js and rename it to i18n/xx.js (where xx is the ISO 639-1 two-letter language code, e.g. de for German, fr for French, ja for Japanese).
  2. Update the _meta block at the top of the file: set code, name (in English), nameNative (name in your language), flag (emoji), author and version. Set completion to the actual percentage of translated keys.
  3. Translate every value string on the right-hand side. Do not rename keys — the engine maps them by key name. Variables like {name} or {n} inside strings must be kept as-is.
  4. Load your file in index.html, overlay.html, and all legal/*.html pages by adding a <script> tag before i18n/i18n.js:
    <script src="i18n/xx.js"></script>
  5. Test the translation by opening the app and clicking your language flag in the bottom-right language switcher. Fix any untranslated strings (shown with the key name).
  6. Open a Pull Request on GitHub with the title i18n: add [Language Name] translation. See README.md § Translation System for full guidelines.
Template to start with — copy the file header:
window.RCH_TRANSLATIONS = window.RCH_TRANSLATIONS || {}; window.RCH_TRANSLATIONS['xx'] = { _meta: { code: 'xx', // ISO 639-1 code (2 letters) name: 'MyLanguage', // Name in English nameNative: 'МойЯзык', // Name in your language flag: 'Us', // Flag author: 'Your Name / GitHub @handle', version: '1.0.0', completion: 0, // 0–100 — update when done rtl: false, // true for Arabic, Hebrew, etc. }, // ── Paste ALL keys from en.js below and translate values ── 'common.app_name': 'Random Challenge Hub', // ... (keep all keys from en.js) };
