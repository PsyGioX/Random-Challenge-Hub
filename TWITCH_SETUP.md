## Быстрая настройка

### Вариант 1: С регистрацией приложения (рекомендуется)

1. **Создайте Twitch приложение:**
   - Перейдите на https://dev.twitch.tv/console/apps
   - Нажмите "Register Your Application"
   - Заполните:
     - **Name**: Game Roulette (любое название)
     - **OAuth Redirect URLs**: `http://localhost:3000` (ваш домен)
     - **Category**: Website Integration
   - Скопируйте Client ID

2. **Настройте Client ID:**
   - В файле `script.js` найдите строку `const TWITCH_CLIENT_ID = 'uo6dggojyb8d6soh92zknwmi5ej1q2';`
   - Замените на ваш Client ID

3. **Используйте:**
   - Запустите приложение
   - Перейдите в "Стример" 
   - Нажмите "🔐 Войти через Twitch"
   - Разрешите доступ в браузере
   - Готово! ✨

### Вариант 2: С демо Client ID (для тестирования)

Можно использовать текущий демо Client ID для быстрого тестирования, но создание собственного приложения более безопасно.

## Как это работает

1. **Нажимаете "Войти через Twitch"** → открывается официальная страница Twitch
2. **Входите в свой аккаунт** → разрешаете доступ приложению к чату
3. **Twitch перенаправляет обратно** → токен автоматически сохраняется
4. **Готово!** → можно отправлять сообщения в чат

## Команды чата

### Для модераторов:
- `!spin` - запустить рулетку
- `!vote` - начать голосование  
- `!timer N` - установить таймер на N минут

### Для зрителей:
- `!join` или `!addme` - добавиться в колесо подписчиков
- Цифры `1-4` - голосование во время опросов

## OBS Integration

1. В OBS добавьте **Browser Source**
2. Используйте URL: `http://localhost:3000/overlay.html?obs=1`
3. Размер: **400×400** пикселей
4. Установите **Chroma Key** на зелёный (#00ff00) если нужен прозрачный фон

### Параметры URL для оверлея:
- `?obs=1` - скрыть панель управления
- `?theme=neon` - установить тему (dark, neon, cyber, streamer, pastel)
- `?chroma=1` - включить зелёный фон для хромакея
- `?pos=top-right` - позиция (top-left, top-right, bottom-left, bottom-right, center)

## Поддержка

Если что-то не работает:

1. **Приложение не создано:** Нажмите кнопку авторизации — покажется инструкция по созданию
2. **Ошибка авторизации:** Проверьте что Redirect URL правильный в настройках приложения
3. **Токен не сохраняется:** Очистите кэш браузера и попробуйте снова
4. **Не работают сообщения:** Убедитесь что авторизованы (показан зелёный статус)
